### [GO! SmartLib](https://github.com/Mavan03/go-smartlib-showcase) — school library management system
Client project for GO! scholengroep Antwerpen, built in a team of four.
Angular front-end, Spring Boot REST API with Smartschool OAuth2 login and JWT, OneRoster and Google Books integrations, and a GitLab CI/CD pipeline that I set up. I built loans and bulk loans, reading lists, imports and the admin dashboard.
`Angular` `Spring Boot` `MySQL` `Docker` `GitLab CI`

### [Padel Manager](https://github.com/Mavan03/padel-manager)
Mobile app for padel players: create and join matches, chat in real time, book courts and track a skill level that changes after competitive matches. Clubs are sorted by GPS distance.
`React Native` `Expo` `Firebase` `TypeScript`

First-person psychological horror game made in a team of four. I built the enemy AI (patrol/chase/attack with sight and hearing), the "don't blink" statue, the cinematic intro and the player controller.
`Unity` `C#` `NavMesh AI` `URP`

VR heist game in Unity, made in a team of four. I trained the ML-Agents security guard that patrols, reacts to noise and remembers where it last saw the player, and built the heist game loop.
`Unity` `C#` `ML-Agents` `VR`
